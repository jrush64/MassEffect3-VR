INSTALL
1. Extract ALL FOUR files (MELE3-VR.bat, dxgi.dll, openxr_loader.dll,
   MELE3VR.ini) into the folder that has MassEffect3.exe - that's
   ...\Mass Effect Legendary Edition\Game\ME3\Binaries\Win64
2. Double-click  MELE3-VR.bat  FROM THAT FOLDER.
3. It asks which VR mode you want (Stereo / Mono / AER / DIBR), then
   which image quality (Low / Performance / Balanced / Sharp / Max /
   Extreme / Ultra). Stereo + Balanced is the recommended default. You can
   change VR mode later in the in-game menu; a resolution change needs
   re-running this installer.
4. Done.

If Windows needs Administrator rights to write into that folder (common
if Steam or EA is under Program Files), the installer will ask for
permission automatically - just click Yes.

BEFORE YOU PLAY  -  IMPORTANT
Turn OFF HDR in Mass Effect's own video options. If you boot the game and it
gets stuck blue/doubled in the headset, that's HDR - go turn it off there.

PERFORMANCE  -  WHAT TO EXPECT
While the game should run fine, the Citadel has CPU cost that will cause
frame drops. Happens even in the flat version. Set your headset's refresh
rate to 90Hz for the smoothest feel in the hubs.

CONTROLS
* INSERT  - open / close the mod menu
* R       - recenter your view
* K       - toggle first-person camera on/off
* F2      - manual flat/mono screen toggle (for full-screen menus)
* F4      - toggle VR on/off
* 1 2 3 4 - load settings profiles
* BACK (gamepad, tap twice) - recenter

You can switch VR mode (Mono / Stereo / AER / DIBR) any time
from the menu (a resolution change needs a game restart).

UNINSTALL
Run  MELE3-VR.bat AGAIN and follow instructions.

Or just delete dxgi.dll and openxr_loader.dll from the game's folder.
